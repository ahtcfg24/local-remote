# Local Remote Control Demo

局域网内浏览器查看并控制本机 macOS 屏幕的最小可用 demo。

## 功能

- 本机运行一个 Node 服务，默认监听 `0.0.0.0:8787`。
- 控制端打开带 token 的网页即可实时查看本机屏幕。
- 网页端支持鼠标移动、左/右/中键、单击、双击、拖拽、拖拽锁定、滚轮、基础文本输入和常见按键。
- 控制台支持屏幕区域全屏、横屏视图切换、缩放、复制当前访问地址和移动端触屏操作。
- 默认固定 token 为 `local-remote-demo`；无 token 或错误 token 无法打开后台或 WebSocket。

## 启动

```bash
npm install
npm start
```

终端会打印类似下面的地址：

```text
LAN URL: http://192.168.x.x:8787/?token=local-remote-demo
```

在同一局域网内的浏览器打开该地址即可。

## macOS 权限

这个 demo 依赖 macOS 权限：

- 屏幕录制：允许终端、Codex 或实际启动服务的进程录制屏幕。
- 辅助功能：允许实际启动服务的进程控制鼠标和键盘。

如果页面提示 `录屏待授权` 或 `辅助功能待授权`，请在系统设置中授权后重启服务。

## 使用提示

- 在屏幕画布上移动鼠标会移动本机光标。
- 直接按下并拖动画布会执行真实拖拽。
- 选择左键、右键或中键后，可用“单击”“双击”按钮在当前指针位置操作。
- 开启“拖拽锁定”后，移动画布会保持鼠标按下状态；关闭时释放。
- 在手机或平板上，轻触画布是单击，长按画布是右键单击。
- 点击“全屏”会先进入页面沉浸全屏，并尝试系统全屏；右上角有退出按钮。
- 全屏浮动工具条和侧栏“视图”区域都支持横屏/原向切换、放大、缩小和重置。
- 桌面端可用 `Ctrl`/`⌘` + 滚轮缩放；触屏设备可双指捏合缩放。
- 开启“平移视图”后拖动画布会移动本地视图，不会发送远程鼠标拖拽。
- 移动端默认“触控板”模式：滑动移动远程光标，轻点左击，双击双击，长按右击。
- 可切换到“直接触摸”模式：点按画面位置直接映射到远程屏幕坐标。
- 移动端底部快捷栏提供模式切换、左击、右击、键盘、放大和缩小。
- 点击“复制地址”可把当前带 token 的控制台地址发给同一局域网设备。

## 可配置环境变量

```bash
HOST=0.0.0.0 PORT=8787 FPS=6 REMOTE_TOKEN=your-token npm start
```

- `HOST`：监听地址，默认 `0.0.0.0`。
- `PORT`：监听端口，默认 `8787`。
- `FPS`：屏幕帧率，默认 `6`，范围 `1-12`。
- `REMOTE_TOKEN`：访问 token；不设置时使用固定默认值 `local-remote-demo`。

## 限制

- 仅用于可信局域网 demo；没有 TLS，不要暴露到公网。
- 屏幕推流用 `screencapture` JPEG 轮询，延迟和帧率不如 WebRTC/ScreenCaptureKit。
- 只支持主屏幕和基础输入控制。
- 不包含账号系统、审计日志、文件传输、剪贴板同步或 NAT 穿透。
