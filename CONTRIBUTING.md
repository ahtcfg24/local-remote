# Contributing

Thank you for helping improve Local Remote.

1. Open an issue before large behavioral or protocol changes.
2. Fork the repository and create a focused branch.
3. Run `npm ci`, `npm test`, and `npm run build:native` on macOS 13 or newer.
4. Keep the browser client dependency-free and mobile-first.
5. Never commit `.env`, `.run/`, access tokens, logs, or screen captures.
6. Submit a pull request describing the user impact, security implications, and validation performed.

Bug reports should include macOS, Node.js, browser, and device versions, plus sanitized logs. By contributing, you agree that your work is licensed under the MIT License.
